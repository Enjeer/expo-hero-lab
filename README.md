# Expo Vision Lab

Задача

Создай одну отдельную демонстрационную страницу, на которой подряд расположены 5 совершенно разных вариантов Hero-блока для EXPO.

Это не финальная главная страница сайта.

Это экспериментальная страница для выбора концепции Hero.

Я прикреплю скриншот текущего Hero.

ВАЖНО

Прикреплённый скриншот — ТОЛЬКО пример текущего состояния и контекста.

НЕ копируй его дизайн.

Не используй его:

композицию;

сетку;

расположение элементов;

структуру;

декоративные элементы;

визуальные приёмы;

типографическую композицию;

расположение изображений.

Фактически представь, что существующего Hero не существует.

Из текущего дизайна разрешено учитывать только фирменную цветовую гамму.

Цель

Нужно исследовать максимально разные направления и найти Hero с настоящим WOW-эффектом.

Не делай 5 красивых, но стандартных корпоративных баннеров.

Нужны концепции, которые заставляют пользователя остановиться на первом экране.

Целевое ощущение:

«Охуенно. Что это?»

И одновременно человек должен сразу понимать:

EXPO занимается выставками, выставочной застройкой, мероприятиями, форумами и созданием event-пространств.

Формат страницы

Создай одну длинную страницу:

EXPERIMENTAL HERO LAB
│
├── HERO 01
├── HERO 02
├── HERO 03
├── HERO 04
└── HERO 05


Каждый Hero должен занимать примерно 100vh и визуально восприниматься как самостоятельный первый экран.

Между вариантами сделай небольшие технические разделители с названием концепции.

Например:

01 — CINEMATIC

02 — SPATIAL OBJECT

03 — KINETIC TYPE

04 — DIGITAL / DISTORTION

05 — UNEXPECTED

Не превращай страницу в обычный каталог.

Каждый Hero должен выглядеть так, будто это реальный первый экран отдельного премиального сайта.

ОБЯЗАТЕЛЬНО: 5 РАДИКАЛЬНО РАЗНЫХ КОНЦЕПЦИЙ

Не делай вариации одного дизайна.

Каждый Hero должен иметь другую визуальную механику и другую идею.

01 — CINEMATIC SPACE

Создай ощущение вступительного кадра фильма.

Главный визуальный объект:

масштабное выставочное пространство / современная выставочная застройка.

Не просто фотография на фоне.

Создай ощущение глубины:

foreground;

middle ground;

background;

свет;

перспектива;

масштаб.

Текст может быть минимальным.

Попробуй создать ощущение, будто пользователь смотрит на огромную выставку через объектив камеры.

Анимация

При загрузке:

плавное появление;

движение камеры;

появление текста;

лёгкий cinematic reveal.

При scroll:

камера начинает двигаться внутрь выставочного пространства.

Hero постепенно трансформируется в следующий блок.

То есть scroll должен ощущаться не как:

Hero → исчез → следующий блок

а как:

Hero → движение камеры → продолжение пространства → следующий блок.

02 — SPATIAL / 3D OBJECT

Сделай главным элементом огромный пространственный объект.

Например:

выставочный стенд;

павильон;

архитектурную конструкцию;

event-инсталляцию.

Объект должен занимать большую часть экрана и частично выходить за его границы.

Создай ощущение настоящего 3D-пространства.

Текст может находиться:

перед объектом;

за объектом;

внутри объекта;

между слоями пространства.

Используй depth и layering.

Анимация

При движении мыши объект может слегка реагировать.

При scroll:

объект приближается;

поворачивается;

раскрывается;

меняет масштаб;

открывает внутреннее пространство.

Если полноценный WebGL/Three.js здесь избыточен, сделай визуально убедительную имитацию через CSS/JS.

Но не отказывайся от идеи только из-за сложности.

03 — KINETIC TYPOGRAPHY

Здесь главным визуальным объектом становится типографика.

Не делай стандартный:

Заголовок + текст + кнопка + картинка.

Сделай слово:

EXPO

частью самого пространства.

Можно использовать:

огромный текст;

экстремальный масштаб;

clipping;

masking;

overlapping;

text behind image;

text inside image;

вертикальное направление;

диагонали;

разрыв букв;

части слова за пределами viewport.

Текст должен выглядеть почти как физический объект.

Анимация

При загрузке:

буквы собираются в слово.

При scroll:

буквы расходятся;

увеличиваются;

перемещаются;

становятся масками;

открывают изображение выставки;

превращаются в следующий блок.

Можно сделать эффект:

EXPO → раскрытие пространства → следующий блок.

04 — DIGITAL / DISTORTION

Самый digital и технологичный вариант.

Можно использовать:

distortion;

noise;

grid;

scanlines;

glow;

particles;

motion blur;

цифровые линии;

интерактивный cursor;

displacement;

динамические маски;

световые эффекты.

Но это должен быть дорогой digital-art, а не дешёвый sci-fi интерфейс.

Основная тема всё равно:

выставочное пространство / архитектура / event.

Например, фотография выставочного стенда может быть частично «разрушена» цифровым эффектом и постепенно собираться обратно.

Интерактив

Попробуй сделать реакцию на курсор:

distortion вокруг курсора;

движение света;

изменение глубины;

частицы;

reveal изображения.

При scroll эффект постепенно меняется и открывает следующий блок.

05 — UNEXPECTED

Полностью свободная концепция.

Здесь нужно придумать самый необычный вариант из всех пяти.

Не повторяй:

cinematic;

3D object;

kinetic typography;

digital distortion.

Придумай собственную визуальную метафору.

Например, выставка может восприниматься как:

портал;

отдельный мир;

архитектурная инсталляция;

физическая конструкция;

бесконечное пространство;

объект, который существует внутри браузера;

сцена, которую пользователь буквально открывает;

другая неожиданная концепция.

Главное:

не делай просто красивый дизайн.

Придумай механику.

Например:

пользователь взаимодействует с объектом → объект раскрывается → внутри обнаруживается выставочное пространство → начинается scroll-transition в следующий блок.

WOW-ЭФФЕКТ

Для каждого Hero задай себе вопрос:

«Есть ли здесь момент, который пользователь запомнит?»

Если нет — переделай.

Не используй стандартные решения только потому, что они проще.

Разрешены:

огромные элементы;

объекты, выходящие за viewport;

необычные маски;

scroll-driven animation;

parallax;

3D;

WebGL;

canvas;

GSAP;

ScrollTrigger;

CSS transforms;

clip-path;

SVG;

particles;

video;

image sequence;

kinetic typography;

cursor interaction.

АНИМАЦИЯ И SCROLL

Это особенно важно.

Минимум 3 из 5 Hero должны иметь заметное интерактивное поведение.

Не ограничивайся hover.

Используй scroll как часть дизайна.

Желательно реализовать:

Hero 01

Scroll → камера движется внутрь выставочного пространства.

Hero 02

Scroll → 3D/пространственный объект приближается и раскрывается.

Hero 03

Scroll → EXPO трансформируется и открывает следующий контент.

Hero 04

Scroll → digital distortion изменяется.

Hero 05

Scroll → собственная уникальная механика.

ВАЖНО ПРО РЕАЛИЗАЦИЮ

Это не просто статичный дизайн.

Сделай рабочие интерактивные прототипы непосредственно на странице.

Если возможно технически:

используй GSAP;

ScrollTrigger;

CSS transforms;

requestAnimationFrame;

SVG;

canvas;

Three.js / WebGL.

Не используй тяжёлую технологию без необходимости.

Но если именно она позволяет получить WOW — используй.

ИЗОБРАЖЕНИЯ

Используй качественные изображения / визуалы, связанные с:

выставочными стендами;

современной застройкой;

архитектурой;

event-пространствами;

павильонами;

выставками;

световыми конструкциями.

Не используй банальные корпоративные стоки:

рукопожатия;

деловые встречи;

люди за столом;

улыбающиеся сотрудники;

абстрактные бизнес-команды.

Главный визуальный объект должен быть связан с пространством и выставками.

ЦВЕТОВАЯ ГАММА

Сохрани только фирменную цветовую гамму существующего сайта.

Но полностью переосмысли её применение.

Можно менять:

пропорции;

контраст;

насыщенность;

градиенты;

прозрачность;

свет;

glow;

фон;

сочетание цветов.

Никакие другие визуальные элементы старого сайта не являются обязательными.

ЛОГОТИП

Старый логотип EXPO можно использовать.

Но не копируй его позицию из старого Hero.

Можно:

переместить;

встроить в композицию;

сделать частью анимации;

использовать как финальный reveal;

интегрировать в пространство.

Не искажать сам логотип.

ТЕКСТ

Используй существующий смысл Hero.

Основная идея:

EXPO;

выставки;

форумы;

конференции;

городские события;

создание и реализация мероприятий.

Не перегружай Hero текстом.

В экспериментальных вариантах допускается сделать текст значительно минималистичнее, если это усиливает концепцию.

ВАЖНО: НЕ ДЕЛАЙ

Запрещено:

копировать старый Hero;

делать похожую композицию;

повторять его сетку;

повторять расположение текста;

повторять расположение изображений;

повторять декоративные элементы;

делать обычный corporate hero;

делать 5 вариантов одного дизайна;

добавлять команду;

превращать страницу в полноценный редизайн сайта.

Нужна только лаборатория Hero-концепций.

ПРОВЕРКА РЕЗУЛЬТАТА

После создания страницы самостоятельно проверь все 5 вариантов.

Для каждого задай вопросы:

Он действительно отличается от старого Hero?

Он отличается от остальных четырёх?

Есть ли WOW-эффект?

Понятно ли, что это EXPO?

Считывается ли связь с выставками?

Есть ли интересная визуальная механика?

Можно ли представить этот Hero на реальном коммерческом сайте?

Есть ли смысл в анимации?

Работает ли scroll как часть концепции?

Не выглядит ли это просто как красивый шаблон?

Если какой-либо ответ неудовлетворительный — переделай соответствующий Hero.

ФИНАЛЬНАЯ ЦЕЛЬ

Мне не нужны 5 «аккуратных» вариантов.

Мне нужны 5 смелых концепций, из которых команда сможет выбрать направление.

Лучше:

1 очень сильный + 4 экспериментальных

чем:

5 одинаково безопасных.

Экспериментируй.

Используй необычные визуальные техники.

Используй движение.

Используй scroll.

Создай ощущение пространства.

Сделай так, чтобы первый экран EXPO был не просто красивым, а запоминающимся интерактивным опытом.
